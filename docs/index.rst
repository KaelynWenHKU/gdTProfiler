gdTProfiler
===========

gdTProfiler identifies human γδ T cells in single-cell RNA-seq data, predicts
their Vδ1/Vδ2 subtype, and scores their cell state against eight reference
expression programmes. It runs on raw counts and does not need TCR sequencing.
